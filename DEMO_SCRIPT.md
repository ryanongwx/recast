# 🎬 Recast Demo Video Script

## Video Structure (90 seconds total)

### Opening Hook (0-10 seconds)
**Visual**: Show the Recast homepage with animated gradient background
**Narration**: "What if you could instantly transform any text into any vibe?"
**Action**: Quick montage of transformation examples

### Problem Setup (10-20 seconds)
**Visual**: Show examples of communication problems
**Narration**: "From corporate jargon to angry emails, we all struggle with tone"
**Action**: Show boring meeting text, angry customer message

### Solution Introduction (20-30 seconds)
**Visual**: Zoom into Recast interface
**Narration**: "Meet Recast - the AI-powered vibe translator"
**Action**: Show the 5 transformation modes with icons

### Core Demo - The Viral Hook (30-60 seconds)
**Visual**: Focus on the "Rant → BBC News Anchor" mode
**Narration**: "Watch this: an unhinged Twitter rant becomes BBC news"

**Action Sequence**:
1. Select "Rant → BBC News Anchor" mode (2 seconds)
2. Paste the example rant: "I CAN'T BELIEVE THEY CANCELLED MY FAVORITE SHOW!!! This is the WORST decision ever made in television history! The executives are completely out of touch with what viewers actually want!!!" (3 seconds)
3. Click "Transform Text" - show loading animation (2 seconds)
4. Reveal transformation: "In entertainment news this evening, network executives have announced the cancellation of a popular television programme, prompting considerable discussion among viewers regarding programming decisions and audience preferences." (5 seconds)
5. Click "Play Original" - show angry voice (3 seconds)
6. Click "Play Transformed" - show calm BBC anchor voice (5 seconds)
7. Show copy-to-clipboard action (2 seconds)

**Narration during demo**: "From unhinged rant... to professional news delivery. Same message, completely different vibe."

### Other Modes Showcase (60-75 seconds)
**Visual**: Quick montage of other transformations
**Action**: 
- Corporate → Gen Z: "Please be advised" → "yo bestie"
- Angry → Passive Aggressive: "This is unacceptable!" → "I'm sure you had your reasons..."
- Meeting → Sports Commentary: Show the sports commentator transformation

**Narration**: "Five powerful modes for every situation"

### Technical Showcase (75-85 seconds)
**Visual**: Show the tech stack and development approach
**Narration**: "Built with Kiro's spec-driven development and ElevenLabs AI"
**Action**: Quick glimpse of code, spec file, and ElevenLabs integration

### Call to Action (85-90 seconds)
**Visual**: Return to homepage with social sharing buttons
**Narration**: "Transform your vibe today. Try Recast now!"
**Action**: Show GitHub link, demo link

## Recording Checklist

### Pre-Recording Setup
- [ ] Clear browser cache and cookies
- [ ] Set browser zoom to 100%
- [ ] Close unnecessary browser tabs
- [ ] Prepare demo text in clipboard
- [ ] Test audio playback functionality
- [ ] Ensure stable internet connection
- [ ] Set up screen recording software (OBS/Loom)

### Recording Settings
- [ ] 1080p resolution minimum
- [ ] 60fps for smooth animations
- [ ] Include system audio for voice playback
- [ ] Record in landscape orientation
- [ ] Use cursor highlighting for better visibility

### Post-Production
- [ ] Add background music (royalty-free)
- [ ] Include smooth transitions between sections
- [ ] Add text overlays for key features
- [ ] Color correct for consistent branding
- [ ] Export in MP4 format
- [ ] Keep file size under 50MB for easy sharing
